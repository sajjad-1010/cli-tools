# cli-tools
a simple and fast cli tools that have your todo's work ready and changable when ever you want 


npx ts-node src/index.ts add "Buy milk" -d 2025-09-15

npx ts-node src/index.ts list

npx ts-node src/index.ts complete <id>

npx ts-node src/index.ts edit <id> "Buy bread" -d 2025-09-20

npx ts-node src/index.ts remove <id>
